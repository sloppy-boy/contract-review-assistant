# 测试合同使用说明

> 6 份测试合同，覆盖高/中/低危、干净、边界全场景。可直接上传到系统审查
> （http://127.0.0.1:5173 工作台 → 在线模式 → 上传），或复制内容粘贴。
> 标准答案（预期结果）源自金标准集 `eval/dataset/` 的植入记录。

---

## 合同清单

| # | 文件 | 场景 | 预期结果（标准答案） | 检查点 |
|---|---|---|---|---|
| 01 | `01_高危_单方解除+预付款90%+验收期短.txt` | 高危缺陷组合 | 🔴 单方解除条件失衡（high）· 🔴 预付款比例过高（high）· 🟡 验收期限过短（medium） | 3 条都命中才算通过（严格口径） |
| 02 | `02_干净_示范文本.txt` | 干净合同（示范文本原样） | ✅ 应报 0~2 条（低误报） | 误报越少越好（误报率指标） |
| 03 | `03_边界_验收期5天争议.txt` | 边界条款（验收期 5 天算不算过短有争议） | ⚠️ 单独报：识别争议/严重度倾向 | 边界组不进主指标，看"有争议"标记 |
| 04 | `04_中危_定金25%.txt` | 定金比例超限 | 🟡 定金条款违规（medium）——定金 25% > 法定 20%（民法典 586） | 应命中「定金条款违规」 |
| 05 | `05_中危_保密条款缺失.txt` | 缺失型缺陷 | 🟡 保密条款缺失（medium）——第八条为"此处空白" | 验证缺失型缺陷识别（抽取不丢空白条款） |
| 06 | `06_高危_个人信息无授权.txt` | 数据合规 | 🔴 个人信息处理无合法依据（high）——要求提供员工/终端用户个人信息且无授权 | 验证数据合规 worker（个保法 6/13 条） |

## 怎么用

1. **在线审查**：http://127.0.0.1:5173 → 工作台 → 拖拽上传（或复制文本粘贴）→ 开始审查（约 18s）
2. **离线演示**：工作台右侧三张卡片一键载入（01=高危 / 02=干净 / 03=边界）
3. **命令行评测**：把合同放进 `eval/dataset/{split}/contracts/` + 写标签，跑 `scripts/run-eval.py`
