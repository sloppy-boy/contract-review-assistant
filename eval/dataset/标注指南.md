# 标注指南（金标准集）

> 本指南与 `app/legal/risk_matrix.py`（风险矩阵）为同一锚：植入缺陷的严重度、规则基线、
> worker 判定、人工复核全部以风险矩阵为准（SPEC 2.6 三源解耦）。

## 1. 风险类型枚举（唯一来源：风险矩阵，13 类）

- **付款/开票**（payment_invoice）：子类型 付款期限过长、逾期付款违约金缺失、预付款比例过高、付款条件不明确、发票开具义务缺失
- **验收交付**（acceptance_delivery）：子类型 验收标准缺失或模糊、验收期限过短、验收不通过的后果不明、交付期限及迟延责任缺失
- **知识产权**（ip）：子类型 知识产权归属不清、交付物侵权担保缺失、使用范围限制不明确
- **数据合规**（data_compliance）：子类型 个人信息处理无合法依据、数据处理范围超出必要、数据安全责任缺失
- **违约责任**（breach_liability）：子类型 违约金过高、违约金过低、责任上限条款缺失、违约救济不完整、定金条款违规
- **解除权**（termination）：子类型 解除权行使期限过短、单方解除条件失衡、解除后果不明
- **保密**（confidentiality）：子类型 保密范围不清、保密期限缺失、违约后果缺失
- **竞业限制**（non_compete）：子类型 竞业限制范围过宽、竞业限制无期限/补偿、排他条款失衡
- **管辖/仲裁**（jurisdiction）：子类型 管辖约定违反专属管辖、只约定仲裁未约定仲裁机构/地点、管辖约定不明确或无效
- **通知送达**（notice）：子类型 送达地址条款缺失、送达方式/生效时间不明
- **不可抗力**（force_majeure）：子类型 不可抗力范围过宽、不可抗力免责滥用、通知义务缺失
- **税费**（tax）：子类型 税费承担约定不明、发票与税负转移条款风险
- **外包分包**（subcontract）：子类型 分包未经同意、分包方责任转嫁不清、总包连带责任缺失

## 2. 严重度 rubric（植入标注据此定级）

- 付款/开票：付款期限 > 90 天且无逾期付款违约金/利息条款 → **medium**
- 付款/开票：付款期限 > 180 天或预付款比例 > 80% 且无担保安排 → **high**
- 付款/开票：付款条件仅依赖单方验收确认，无客观时限 → **medium**
- 验收交付：验收标准仅'按国家/行业标准'而无具体指标，或验收期限 < 5 个工作日 → **medium**
- 验收交付：验收以对方单方/无期限确认为准，或验收不通过无任何救济 → **high**
- 验收交付：交付期限缺失或迟延交付无违约金 → **medium**
- 知识产权：定制/委托开发成果的知识产权归属未约定 → **high**
- 知识产权：无第三方知识产权侵权担保与赔偿条款 → **medium**
- 数据合规：涉及个人信息处理但无合法依据/授权条款 → **high**
- 数据合规：数据共享范围、留存期限、删除义务未约定 → **medium**
- 违约责任：违约金比例 > 30% 合同额（明显过高，民法典 585 可调减） → **high**
- 违约责任：违约金比例 20%~30% 或与损失预估明显不匹配 → **medium**
- 违约责任：违约金过低（< 10%）且无赔偿损失兜底，违约成本趋零 → **medium**
- 违约责任：定金比例 > 主合同标的额 20%（超出部分不产生定金效力） → **medium**
- 解除权：解除权仅归一方且条件宽泛（如'甲方可随时解除'） → **high**
- 解除权：解除权行使期限过短或解除后果（已付款/存货处理）未约定 → **medium**
- 保密：涉及商业秘密但无保密条款，或保密期限/违约责任缺失 → **medium**
- 竞业限制：竞业限制期限、地域、范围无边界（如'全国全行业永久'） → **high**
- 竞业限制：排他供应条款无期限或与采购量不对价 → **medium**
- 管辖/仲裁：约定仲裁但未约定仲裁机构或仲裁地（仲裁协议无效风险） → **medium**
- 管辖/仲裁：管辖约定违反专属管辖或选择与争议无实际联系地点 → **high**
- 管辖/仲裁：管辖条款措辞含糊（'均可'/'或'导致选择不明） → **medium**
- 通知送达：无送达地址条款或仅约定一种不可靠方式（如仅邮件） → **low**
- 不可抗力：不可抗力范围扩张至一方经营风险/恶意行为（规避违约责任） → **high**
- 不可抗力：不可抗力条款无通知义务与证明时限（民法典 590） → **medium**
- 税费：约定'一切税费由对方承担'等概括条款且税种不明 → **low**
- 外包分包：允许分包但未约定需经书面同意，或分包方违约责任未约定由总包承担 → **medium**

## 3. 植入记录 = 标准答案

植入缺陷组每份合同的 `labels/{id}.json` 中 `defects[]` 为唯一标准答案，
三元组 `(clauseId, riskType, severity)` 逐字段完全一致才计命中。

## 4. 人工抽样复核（~20%）

已按 `meta.json` 的 `manualAudit` 清单随机抽查植入记录与标注指南的一致性。

## 5. 盲标质检（Qwen 第二家族）

`python eval/blind_label.py` 用硅基流动 Qwen 盲标植入组，仅评估标注质量
（植入记录是否合理、是否漏植），绝不用于修正 worker 输出。
